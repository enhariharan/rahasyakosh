## `eff_large.txt`
The EFF Long Wordlist (7,776 words) by the Electronic Frontier Foundation,
<https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases>.

Source file: <https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt>; the only change is that the
leading dice numbers were removed (one word per line, original order).

# Further reading

## Free, beginner-friendly
- *Serious Cryptography* (Jean-Philippe Aumasson), the best single book for programmers.
- *Cryptography Engineering* (Ferguson, Schneier, Kohno), practical thinking about getting it right.
- Cryptopals challenges, <https://cryptopals.com>: learn by breaking toy systems.
- Dan Boneh's free Cryptography course on Coursera.
- Troy Hunt, *Have I Been Pwned*, and its k-anonymity design.

## Standards used here
- RFC 9106 — Argon2.
- RFC 5869 — HKDF.
- RFC 8439 — ChaCha20-Poly1305 (XChaCha20 is a draft extension of it).
- RFC 4226 and RFC 6238 — HOTP and TOTP.
- EFF, "Deep Dive: EFF's New Wordlists for Random Passphrases".
- OWASP Password Storage Cheat Sheet.

## Rust and security
- The Rust Book and *Rust API Guidelines*.
- RustCrypto project docs, <https://github.com/RustCrypto>.
- `zeroize` and `subtle` crate documentation.

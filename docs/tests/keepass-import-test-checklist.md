# KeePass .kdbx import test checklist (US-IMP-02)

A manual pass over **Settings → Import passwords** in the Linux desktop app and over the CLI.
About 20 minutes. Use a throwaway vault:

```
RK_VAULT=/tmp/rk-test/vault.db RK_CONFIG_HOME=/tmp/rk-test/cfg rahasyakosh
```

Generate the sample KDBX file first (password: `testpass`):

```
cargo run -p rahasyakosh-transfer --example gen_kdbx_fixture
# writes: crates/transfer/tests/fixtures/sample.kdbx
```

`✔` works · `✘` does not · `?` does something else (say what).

## Files to prepare

Put these in a folder such as `/tmp/rk-import/`:
- `sample.kdbx` — generated by `gen_kdbx_fixture` (password: `testpass`)
- A real KeePass 4 database exported from KeePass or KeePassXC (password: whatever you set), with at least one group, one TOTP entry, and one custom field.

---

## 1. Desktop app — file selection

| Check | Expected | Result | Notes |
| ----- | -------- | :----: | ----- |
| **Choose a file…** and pick `sample.kdbx` | A password prompt appears (not the column picker) | | |
| Enter wrong password and click **Preview** | A readable error: "not a valid KeePass database: …"; no items shown | | |
| Re-enter `testpass` and click **Preview** | Preview shows 7 items to add, 1 skipped (empty title + URL); format reported as "keepass" | | |
| Choose a non-KDBX file (e.g. `chrome.csv`) | The normal CSV preview appears (no password prompt) | | |
| Choose an empty file | A readable error; no password prompt | | |

## 5. CLI

| Check | Expected | Result | Notes |
| ----- | -------- | :----: | ----- |
| `rk import /tmp/rk-import/sample.kdbx` | Prompts for a password; correct password imports 7 items | | |
| `rk import /tmp/rk-import/sample.kdbx` (wrong password) | Error message; vault unchanged | | |

## 6. Real KeePass database

| Check | Expected | Result | Notes |
| ----- | -------- | :----: | ----- |
| Import your real `.kdbx` with correct password | All logins appear; groups become tags; TOTP entries work | | |
| Entries in the KeePass Recycle Bin | Not imported | | |
| Entries with multi-line notes | Notes preserved verbatim | | |
| Large database (100+ entries) | Import completes in < 5 s | | |

## 7. Accessibility and language

- [ ] Keyboard only: reach the password field, **Preview** button and **Add N items** with `Tab`; focus is visible throughout.
- [ ] With Orca on: the password prompt label is announced; "wrong password" error is announced live; item count in the summary is announced.
- [ ] 200 % zoom: password field and buttons do not overflow.
- [ ] Switch app language (Hindi, Tamil, Urdu …): the "Password" label and error messages are translated; Urdu reads right-to-left. Native speakers: note any wrong wording.
